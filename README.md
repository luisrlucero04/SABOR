Aplicación web de recetas desarrollada como proyecto grupal para la asignatura de Ingeniería de Software (Semestre VI). 
La meta a futuro es integrar una API de inteligencia artificial que genere recetas para los usuarios.
Sitio en producción: https://sabor-2ef5c.web.app

Tecnologías
-HTML, CSS y JavaScript (sin frameworks)
-Firebase Authentication
-Cloud Firestore
-Firebase Hosting
-GitHub Actions (CI/CD)
